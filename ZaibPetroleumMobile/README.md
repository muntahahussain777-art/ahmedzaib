# Zaib Petroleum Mobile

PC-compatible Flutter app — same SQLite file as desktop: **DiselPetrolPump.db**

## Tables (PC same)
AddCustomer, PetrolAdd, AddDealer, DieselLedgerCredit, AddStock, DieselLedgerDebit, StockDiesel, BankTransactions

## Backup / Restore
1. PC → Backup And Restore → `DiselPetrolPump_backup.db`
2. Phone pe file copy karein
3. App → **Backup / Restore** → **Restore PC Backup (.db)**
4. Saari entries load ho jayengi

## Run
```bash
flutter pub get
flutter run
```
